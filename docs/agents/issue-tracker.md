# Issue tracker: Local Markdown

Issues and specs live in Git-ignored `.scratch/`.

- Specs: `.scratch/<feature>/spec.md`.
- Issues: `.scratch/<feature>/issues/<NN>-<slug>.md`,
  numbered from 01, one issue per file.
- Triage: `Status:` near the top, using `triage-labels.md`.
- Comments: append under `## Comments`.
- Publishing means creating the appropriate local file.
- Fetching means reading the referenced file.
- Resolve ambiguous issue numbers by asking for the feature.
